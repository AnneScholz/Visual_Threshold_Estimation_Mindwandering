# Visual_Threshold_Estimation_Mindwandering
Contains data and scripts for all figures presented in "Visual Thresholds Estimation is Biased by Phases of Inattention"

the main script is "all_figures.m"
"data"-folder contains several .mat-files, that will be loaded into "all_figures.m"
"GetOffset4OverlappingDataPoints.m" and "ONOFFboxplot.m" are helper-functions, which are necessary for several plots
"figures"-folder contains the resulting figures
